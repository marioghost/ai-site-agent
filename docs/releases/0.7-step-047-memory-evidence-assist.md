# Release 0.7 — Step 047: Advisory Memory evidence assist

**RFC-100 Step 047**  
**Lifecycle state:** Implemented — flag default OFF

## Summary

Wires **advisory** Memory region reads into Reasoning behind `memory_evidence_assist_enabled` (Settings, default `false`).

```
ReasoningService._coordinate_pipeline()
  → RPS.prepare_query()
  → MemoryAssistPolicy.attempt()
  → EpistemicMemoryService.read_region(DEPLOYMENT corpus)
  → MemoryAssistResult on PreparedRetrieval
  → RPS.assemble_evidence() once
  → RPS.finalize_pipeline()
  → sufficiency diagnostics enrichment (advisory)
  → speech act → Language (unchanged)
```

**No claim proposition text** in prompts, logs, or user-visible output.

## Feature flag

| Flag | Surface | Default | Effective when |
|------|---------|---------|----------------|
| `memory_evidence_assist_enabled` | Settings | `false` | `REASONING_SERVICE_ENABLED` + flag ON + `cache_namespace_v2_enabled` |

Behavior matrix:

| Reasoning | Assist | Result |
|-----------|--------|--------|
| OFF | OFF | Release 0.6 legacy |
| OFF | ON | Assist skipped (`reasoning_disabled`) |
| ON | OFF | Release 0.6 Reasoning path |
| ON | ON (+ cache v2) | Step 047 advisory read |

## Modules

| File | Role |
|------|------|
| `memory_assist_types.py` | `MemoryAssistResult` DTO |
| `memory_request_builder.py` | `MemoryRegionRequest` from `PreparedRetrieval` |
| `memory_assist_policy.py` | Flag checks, one `read_region()`, fail-open |

Corpus isolation uses `MemoryCorpusScope.DEPLOYMENT` — **no Reasoning-side source resolver**.

## Cache namespace

When assist is effective:

- `memory_evidence_assist: "v1"` (otherwise `"off"`)
- `corpus_boundary_fingerprint` from Settings hosts
- `memory_version` (requires `cache_namespace_v2_enabled`)

Assist ON without cache v2 → skipped at runtime (`cache_namespace_v2_required`).

## Evidence safety

- `usable_for_evidence=true` only when supported claims have loaded evidence + observation refs
- Sufficiency enrichment is diagnostic only; strong retrieval remains authoritative
- Empty/sparse Memory never reduces sufficiency or forces clarify/refuse
- No second retrieval / Qdrant pass
