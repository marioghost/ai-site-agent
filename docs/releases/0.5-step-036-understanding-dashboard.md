## Summary

Admin-only **Understanding** page (`/understanding`) is a read-only operational
panel for inspecting epistemic hypotheses surfaced from Epistemic Memory.

Semantic rule preserved in UI copy:

- A tension is an **epistemic hypothesis**
- It is **not** knowledge, belief, or a verified fact
- Labels use uncertainty: “Possible support deficit”, “Possible conflict”

## UI behavior

- Summary metrics: total possible issues, support-deficit count, conflict count, page
- Filters: All / Possible support deficit / Possible conflict (client filter; resets to page 1)
- Pagination: client pagination over fetched API pages (`page` / `page_size` contract)
- Expandable provenance: full summary, claim / observation / evidence IDs, diagnostic JSON
- Copy JSON for engineering inspection
- Empty / loading / error states
- **No** resolve / investigate / classify / edit / persist controls
