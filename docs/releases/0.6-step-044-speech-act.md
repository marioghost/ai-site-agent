# Release 0.6 — Step 044: Speech-act selection (advisory)

**RFC-100 Step 044**  
**Lifecycle state:** Implementation → Engineering Ready (after review)

## Summary

Introduces **source-scoped speech-act selection** inside `ReasoningService`
(`answer` | `qualify` | `clarify` | `refuse`), driven by Step 043 sufficiency.

**Advisory / deferred activation:** diagnostics and typed fields are populated;
**final answer text, sources, prompts, and LLM behavior are unchanged.**
No approved separate behavior-activation flag exists — Language consumption
is deferred to a later step. Rollback: `REASONING_SERVICE_ENABLED=false`.

## Semantic rules

- Speech acts are **source-scoped** (website evidence), not world-truth.
- **Refuse** = insufficient site evidence — not “false in the world.”
- **Qualify** preferred over false certainty (completeness risk / unknown).
- Reasoning **selects** the act; Language **renders** wording (not yet wired).
