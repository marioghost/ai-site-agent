# 5. Load model

**LOCKED DECISION — profile:**

| Parameter | Frozen value | Source |
|-----------|--------------|--------|

| Maintenance | Observe budget **0** / no unexpected investigation spike | Step 063 |

# 8. Rollback contract

**Separate layers — do not merge.**

| Layer | Step 066 | Notes |
|-------|----------|-------|
| **Operational kill-switch** | **Optional** evidence | Env/Settings false per FEATURE_FLAGS; not a substitute for code drill |

| **Service restart (“pod kill”)** | **Mandatory** (designated `/opt`) | Restart backend service under light traffic; prove recovery. **Not** DB restore. **Not** force-push. |
| **Database restore** | **Forbidden** by default | See §10 |
| **Qdrant restore/wipe** | **Forbidden** | See §11 |

### Mandatory code tip drill sequence (LOCKED)

1. Record pre-drill identity (`origin/main`, `/opt` build-info, `/api/build`).  
2. Place known-good tip **`148138e`** on the deployable mainline **without force-push** (approved revert merge, temporary tip procedure, or operator-authorized equivalent — exact git mechanics in execution runbook).  
3. `sudo bash deploy/manage_deploy.sh deploy full`  
4. verify-release + smoke (policy) prove `148138e`.  
5. Restore tip **`a41198f`** (or execution-time current 1.0 tip) on mainline.  
6. `sudo bash deploy/manage_deploy.sh deploy full`  
7. verify-release + smoke prove current tip; chain aligned.

**One Command remains sole deploy authority.** No alternate rollback script that syncs `/opt` outside `deploy full`.
