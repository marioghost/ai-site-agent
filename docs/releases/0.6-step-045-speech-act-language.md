# Release 0.6 — Step 045: Language speech-act activation

**RFC-100 Step 045**  
**Lifecycle state:** Implementation → Engineering Ready (after review)

## Summary

First intentional **user-visible** behavior change in Release 0.6.

Language consumes the typed speech-act decision from Reasoning when both
`REASONING_SERVICE_ENABLED` and `REASONING_SPEECH_ACTS_ENABLED` are ON.

Reasoning still **selects**; Language **renders**. No reasoning logic moved
into prompts.

## Activation matrix

| Reasoning | `REASONING_SPEECH_ACTS_ENABLED` | Behavior |
|-----------|--------------------------------|----------|
| OFF | * | Exact legacy; speech-acts flag ignored |
| ON | OFF | Step 044 advisory-only (answer unchanged) |
| ON | ON | Language applies act |

Default for the new flag: **false** (independently rollbackable).

## Delivered

| Item | Path |
|------|------|
| Flag | `REASONING_SPEECH_ACTS_ENABLED` |
| Language render | `backend/app/services/language/` |
| Rag / stream wiring | `apply_speech_acts` on answer / iter_events |
| Cache isolation | `speech_act_language` in retrieval namespace |
| Docs | `docs/LANGUAGE_SPEECH_ACTS.md`, `REASONING_SERVICE.md` |
| Tests | `backend/tests/test_speech_act_language.py` |

## Speech-act UX

| Act | Behavior | LLM |
|-----|----------|-----|
| answer | Legacy path | 1 call |
| qualify | Answer + localized limitation | ≤1 call |
| clarify | Deterministic one-question clarify | 0 |
| refuse | Site-scoped refusal wording | 0 |

## Sources

- answer / qualify: preserved  
- clarify / refuse: not presented as evidence for the act  

## Non-goals

- No second LLM call; no extra retrieval  
- No Epistemic Memory / tension imports in Language  
- No Release 0.6 closure in this step
