# Release 0.6 — Step 041: Thin RPS + Reasoning coordinator

**RFC-100 Step 041**  
**Lifecycle state:** Implementation → Engineering Ready (after review)

## Summary

Thins `RetrievalPipelineService` into a **legacy coordinator** with three
explicit stages (`prepare_query` → `assemble_evidence` → `finalize_pipeline`).
When **both** `REASONING_SERVICE_ENABLED` and `EVIDENCE_ASSEMBLY_ENABLED` are ON,
`ReasoningService` owns stage order and injects the pipeline into Rag once
(language unchanged). No third orchestration flag.

## Responsibility map (RPS)

| Responsibility | Classification | Step 041 |
|----------------|----------------|----------|
| Intent classification | Reasoning (deferred) | Stay — `prepare_query` adapter |
| Query expansion | Deferred / ambiguous | Stay — `prepare_query` |
| Profile boost config | Legacy coordination | Stay — `prepare_query` |
| EA / DFP invocation | Evidence Assembly | `assemble_evidence` (clear boundary) |
| Broad inject | Deferred | Stay — `finalize_pipeline` |
| Canonical selection | Deferred | Stay — `finalize_pipeline` |
| Bilingual dedupe | Deferred | Stay — `finalize_pipeline` |
| Context builder / `prompt_text` | Language (deferred) | Stay — `finalize_pipeline` |
| Diagnostics aggregation | Diagnostics | Stay on RPS |
| `run()` composition | Legacy coordination | Thinned to three stage calls |

## Flag matrix

| Reasoning | EA | Path |
|-----------|----|------|
| OFF | OFF | Rag → RPS.`run` → DFP |
| ON | OFF | Reasoning → Rag → RPS.`run` → DFP |
| OFF | ON | Rag → RPS.`run` → EA → DFP |
| ON | ON | Reasoning orders stages → EA → finalize; Rag language via `pipeline_provider` |

## Diagnostics (additive)

- `reasoning_path`
- `evidence_assembly_path`
- `retrieval_coordinator` = `rag` \| `reasoning`

## Non-goals

- No Language extraction; no Memory; no RPS deletion
- No move of intent/broad/canonical/context into EA or Reasoning internals
- No answer / prompt / LLM / streaming protocol changes

## Performance

| Concern | Impact |
|---------|--------|
| Extra Python calls | Stage method calls; provider indirection when both ON |
| DTO allocations | `PreparedRetrieval` per pipeline run |
| Retrieval / LLM | **Exactly one** each |
| Tokens / context copies | **None** added |
