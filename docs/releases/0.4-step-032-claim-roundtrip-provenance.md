- Shadow persist → `EpistemicMemoryService` read roundtrip (observation, claims, evidence links)
- Provenance fields consistent across observation, claim, and evidence layers
- `scope_json` carries `proposal_kind` and source context
- ADR-0001 behavior: re-SI reuses observation row; first `content_hash` preserved
- Flag OFF: no roundtrip rows

- No Memory Integration / revision engine
- No chat/retrieval/reasoning changes
