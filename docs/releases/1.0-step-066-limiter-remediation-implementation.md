## 1. Implementation summary

Replaced per-request `threading.Semaphore` replacement in `ConcurrencyManager.configure()` with a **single-domain condition + counter admission gate** per limiter kind (`chat`, `llm`, `embed`, `bg_embed`, `bg_llm`).

- Unchanged limits → **no-op** (no domain recreation).  
- Increased / decreased limits → `set_limit` on the **same** gate (process-wide holders ≤ new target for new admissions; over-limit holders drain naturally).  
- Public APIs preserved: `chat_slot` / `llm_slot` / `embed_slot` / background slots, `OverloadedError`, timed wait semantics.  
- Parent DB-session remediation and Steps 063–065 untouched.
