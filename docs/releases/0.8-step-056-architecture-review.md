**PROVEN BY CURRENT CODE** — `parity_runner.load_golden_smoke()` (~26–31):

- **Does not call `PRESETS`, `load_preset`, or `from_settings`**

Unit golden path monkeypatches `RagService` / `ExecutiveService` — **no real retrieval, no live Knowledge Profile**.

| Step | Title | Detail |

| **057** | Release 0.8 | — |

**PROPOSED MINIMAL INTERPRETATION:**

Make CI golden policy **fail-closed**: the golden smoke suite must declare and load only under `fixture_profile == "generic_corporate"`, enforced in the golden loader (and kept in schema tests). This is a **CI / test-suite** step — not a production Settings rewrite, not a ranking change, and not Release 0.8 closure (057).

## 3. Existing implementation gaps

1. Soft policy only (JSON string + schema assert); loader does not fail-fast.
2. Unit golden never materializes a Knowledge Profile — “generic only” is documentary for the mocked path.
3. Industry `PRESETS` remain correctly used in **non-golden** unit tests (must stay allowed).
4. Optional live / ops golden against a real site is out of unit CI — must stay documented separately.

## 9. Alternative designs considered

| Option | Description | Verdict |
|--------|-------------|---------|
| **A. Harden `load_golden_smoke` + schema** | Fail if `fixture_profile != "generic_corporate"`; README clarify non-golden industry tests OK | **Recommend** |
| **B. Materialize `PRESETS["generic_corporate"]` in pytest fixture** | Inject profile into golden | Optional later; dead weight for mocked RagResult today |
| **C. CI env `GOLDEN_FIXTURE_PROFILE` only** | Scripts check env | Weak alone; skippable locally |
| **D. Rewrite live Settings / ban all industry PRESET tests** | Production + CI purge | **Forbidden** |
| **E. Combine with Step 057 release closure** | Bundle | **Forbidden** |

---

## 10. Recommended option

**Option A** — **PROPOSED MINIMAL INTERPRETATION**

1. In `load_golden_smoke()`: require `fixture_profile == "generic_corporate"` (raise clear `ValueError` otherwise).
2. Keep schema test assert; optionally reject industry preset ids if they ever appear inside golden JSON body.
3. Update `golden/README.md` one short paragraph: golden CI is generic-only; other unit tests may still use industry `PRESETS`.
4. Do **not** change production Settings, ranking, Memory, Shadow, Assist, or KP generation.
5. Do **not** start Step 057.
