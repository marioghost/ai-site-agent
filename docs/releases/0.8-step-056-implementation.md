## Enforcement point

`load_golden_smoke()`:

1. Load golden JSON from `GOLDEN_PATH`
2. Require `suite == "smoke"` (unchanged)
3. Require `fixture_profile == "generic_corporate"`
4. Otherwise raise `ValueError` (fail closed — no silent default, no env override)

Example:

```text
Golden smoke requires fixture_profile='generic_corporate'; got 'bank_financial'.
```

## Fail-closed contract

| Input `fixture_profile` | Result |
|-------------------------|--------|
| `"generic_corporate"` | load succeeds |
| missing / `null` / `""` / industry id / any other value | `ValueError` |
