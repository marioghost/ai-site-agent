# RFC-100 Step 047 — Architecture Review: Memory Assist (Advisory)

**Status:** Provisionally accepted — **implementation NOT approved**  
**Prerequisite:** Step 046 dual-scope extension (deployment corpus isolation)  
**Date:** 2026-07-28

## Executive summary

Step 047 wires **advisory** Memory reads into Reasoning behind `memory_evidence_assist_enabled` (default **OFF**). Memory must not become a second retrieval engine, must not inject claim propositions into prompts, and must preserve **one Qdrant execution** and **at most one LLM call**.

## Source-scope decision (approved)

The provisional Step 047 design proposed `MemoryAssistSourceResolver` to enumerate source IDs from Memory anchors. The **Source-Scope Architecture Review** rejected that pattern:

| Rejected | Approved |
|----------|----------|
| Reasoning resolves individual source IDs | Epistemic Memory owns corpus isolation |
| `LIMIT 50` anchor enumeration | Full deployment boundary from Settings |
| Implicit “all anchored sources” corpus | Explicit `MemoryCorpusScope.DEPLOYMENT` |

### Step 047 caller contract (after Step 046 extension)

Reasoning constructs `MemoryRegionRequest` with:

```python
isolation=MemoryIsolationScope(corpus_scope=MemoryCorpusScope.DEPLOYMENT)
```

plus cognitive region filters (`topic_key`, `page_roles`, `document_types`, …).

Reasoning must **not**:

- import `memory_corpus_resolver`
- implement `MemoryAssistSourceResolver`
- pass arbitrary global source lists for production chat

Engineering callers may still use explicit `source_id` / `source_ids` for diagnostics and source-detail tools.

### Deployment corpus boundary

Resolved inside Epistemic Memory from the **canonical Settings row** (`SettingsRepository.get()` — lowest `id`):

1. `settings.allowed_domains_json` (normalized hosts)
2. Fallback: host from `settings.site_url`

Fail-closed when unconfigured: empty region, `corpus_scope_unconfigured`, no global read.

Subdomain semantics reuse `is_allowed_domain()` (crawler-aligned).

### Cache identity (Step 047)

Step 047 cache keys will combine:

- `MemoryRegionView.corpus_boundary_fingerprint()` (hosts + boundary version)
- region-filter fingerprint
- `memory_version`
- memory assist version

No wiring in Step 046.

## Minimal pipeline (unchanged intent)

```
Reasoning (information need)
  → MemoryRegionRequest(isolation=DEPLOYMENT, cognitive filters)
  → EpistemicMemoryService.read_region()
  → MemoryRegionView (advisory)
  → Reasoning assesses usefulness
  → Evidence Assembly (single retrieval execution)
  → sufficiency → speech act → Language
```

## Non-goals (Step 047 — not started)

- No feature flag in Step 046
- No chat / streaming changes until flag ON + staging validation
- No claim text in prompts without linked observation content
- No second Qdrant pass driven by Memory
