# Release 0.4 — Step 029: ClaimExtractionFromSI mapper

**RFC-100 Step 029**  
**Lifecycle state:** Implementation → Engineering Ready (after review)

## Summary

Maps existing Source Intelligence output into **in-memory claim proposal DTOs**. No persistence, no integration hooks.

## Delivered

| Item | Path |
|------|------|
| Mapper | `backend/app/services/epistemic_memory/claim_extraction_from_si.py` |
| DTOs | `backend/app/services/epistemic_memory/proposal_types.py` |
| Tests | `backend/tests/test_claim_extraction_from_si.py` |

## Proposal fields

Each `ClaimProposal` includes:

- `proposition` — attributed claim text
- `attributed_to` / `provenance_kind` / `provenance_ref`
- `confidence` when SI provides it
- `evidence` — `EvidenceProposal` with excerpt, content hash, source id, observation key hint
- `epistemic_status` — `"proposal"` (not yet integrated)
- `scope_json` — source id, url, document_type, proposal_kind
