# Release 0.5 — Step 035: Understanding tensions API

**RFC-100 Step 035**  
**Lifecycle state:** Implementation → Engineering Ready (after review)

## Summary

Admin-only, read-only `GET /api/understanding/tensions` exposes in-memory
epistemic hypotheses (tensions) from `TensionSurfacingService`.

Semantic reminder: a Tension is **not** knowledge, belief, or fact — it is an
epistemic hypothesis about a *possible* problem in Epistemic Memory.

## Delivered

| Item | Path |
|------|------|
| API | `backend/app/api/understanding.py` |
| Schemas | `backend/app/schemas/understanding.py` |

| Docs | `docs/TENSION_SURFACING.md` (semantics + HTTP) |

## Behavior

- Admin auth via `require_admin`
- Computes tensions per request (no persistence)
- Pagination: `page` / `page_size`
- Deterministic ordering
- Provenance via claim / observation / evidence IDs + summary
- No ORM models in response payloads

## Explicit non-goals

- No maintenance execution / investigation planning
- No chat / retrieval / Executive / reasoning integration
- No tension DB writes
