## Implementation summary

Collapsed API chat dispatch so both `POST /api/chat` and `POST /api/chat/stream` use **ExecutiveService only** after evaluating `KNOWLEDGE_OS_EXECUTIVE_ENABLED`.

- Executive unset/true → call `ExecutiveService` exactly once.
- Executive explicit `false` → controlled unavailable (HTTP **503** / SSE `error_type=executive_disabled`); no Rag, Reasoning, or retrieval.
- Internal Executive → Reasoning / Rag degradation retained.
- Dispatch path vocabulary: `executive` \| `executive_disabled` (no `legacy` from API dispatch).

## Routing behavior before and after

### Before

```text
API → if Executive → ExecutiveService
    → elif Reasoning → ReasoningService   # API bypass
    → else → RagService / RagStreamingService
```

### After

```text
API → if Executive false → controlled unavailable (503 / SSE executive_disabled)
    → else → ExecutiveService only
         → (internal) ReasoningService when enabled
         → (internal) Rag / RagStreaming degrade when Reasoning false
```

## Emergency non-stream behavior

| Contract | Implementation |
|----------|----------------|
| HTTP status | **503** |
| Detail | `EXECUTIVE_DISABLED_DETAIL` constant in `chat.py` |
| Engines | Executive / Reasoning / Rag **not** constructed |
| Logging | `path=executive_disabled` via `resolve_chat_path()` before dispatch |
| Fallback | None |

## Emergency stream behavior

| Contract | Implementation |
|----------|----------------|
| Transport | Normal SSE (`StreamingResponse`) |
| Events | Exactly one `error` with `error_type=executive_disabled` |
| Message | Same `EXECUTIVE_DISABLED_DETAIL` |
| Token / final | Not emitted |
| Lifecycle log | `stream_lifecycle=error`, `error_type=executive_disabled` |
| Close | `[DONE]` then generator return |

## Internal degradation confirmation

- `ExecutiveService` still routes to `ReasoningService` when Reasoning enabled.
- `ExecutiveService` still uses Rag / RagStreaming when Reasoning disabled.
- `ReasoningService` still uses Rag language/cache/finalization internals.
- No Rag / Reasoning / EA / speech redesign.
